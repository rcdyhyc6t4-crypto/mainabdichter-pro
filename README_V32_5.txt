mainabdichter PRO V32.5

- Enthält alle Änderungen aus V32.4.
- Zusatzarbeiten stehen im Arbeitsnachweis unter:
  „Auf Kundenwunsch wurden folgende zusätzliche Arbeiten ausgeführt“.
- Zusatzmengen können einer vorhandenen Auftragsposition zugeordnet werden.
- Beispiel: 12 lfm beauftragt + 3 lfm zusätzlich = 15 lfm abzurechnen.
- Eine neue Rechnungsposition entsteht nur bei einer neuen Leistungsart.
- Zusatzarbeiten ohne bestätigte Kundenbeauftragung werden nicht zur Rechnung addiert.
- Die Rechnungszuordnung wird vor dem Baustellenabschluss übersichtlich angezeigt.
